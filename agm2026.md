# Perception.

## The eyes and ears of the cart

---
layout: team
icon: map-pin
steps:
  - { label: Build the map, text: "LIO-SAM fuses LiDAR, IMU, wheel odometry and GPS into a drift-free 3D point cloud" }
  - { label: Annotate it, text: Downsample it and draw the road layout with Lanelet2 }
  - { label: Localize live, text: "An EKF plus NDT scan matching give the cart's exact pose 10 times a second" }
facts:
  - { icon: map-pin, label: Built off-vehicle, caption: From recorded drives; loaded into RAM at startup }
  - { icon: lidar, label: GPS is only a backup, caption: "Startup and the campus geofence, not lane-level accuracy" }
tools: [ROS 2, LIO-SAM, GTSAM (via LIO-SAM), Lanelet2, EKF, NDT, TF transforms]
skills:
  - SLAM & factor graphs
  - { text: State estimation, caption: Kalman filters fusing IMU and wheel odometry }
  - 3D geometry & coordinate frames
industry:
  text: Geofenced robotaxis drive on prebuilt HD maps and localize against them, just like this.
  caption: "Autoware, the open-source driving stack, also uses NDT, an EKF and Lanelet2"
handoff: "map + pose → Planning & Control"

# Mapping & localization.

## Builds the map, then knows where we are on it

---
layout: team
icon: steering-wheel
steps:
  - { label: Plan the route, text: The sequence of waypoints to the next stop }
  - { label: Decide the behaviour, text: "A state machine: cruise, yield, avoid obstacles, stop, handle intersections" }
  - { label: Drive it, text: "One MPC on the VCU turns the trajectory into steering, throttle and braking" }
facts:
  - { icon: steering-wheel, label: Comfort envelope, caption: "Acceleration, braking and jerk limits built into the MPC" }
  - { icon: cone, label: Watchdog, caption: "No command in time? The VCU brings the cart to a controlled stop" }
tools: [ROS 2, Model predictive control, State machines, QNX (RTOS)]
skills:
  - Control theory & optimization
  - { text: Vehicle dynamics, caption: "Speed and steering are coupled: slow down before turning" }
  - { text: Real-time & safety-critical code, caption: "Watchdogs, fail-safes, embedded RTOS" }
industry:
  text: "Automotive ADAS, robotics and aerospace all rely on MPC and safety watchdogs like these."
  caption: Behaviour state machines are how robotaxis decide when to yield, stop or go
handoff: "commands → steering, throttle, brakes"
